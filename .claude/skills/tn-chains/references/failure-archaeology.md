# TN Chains failure archaeology

Rejected work is evidence of what **not** to reproduce.

## V001 / V002 and early generated animation failures

Treat as REJECTED / ARCHAEOLOGY ONLY.

Known failure patterns:
- proxy/square or otherwise non-character-like visualizations treated as progress;
- tiny/incorrect arm proportions;
- circular/mechanical motion;
- no convincing XP32 character biomechanics;
- arm acting independently of torso/pelvis;
- artificial poses;
- rigid chain substitutes;
- technical export used as proof of quality.

Do not copy their motion even if files are technically reusable.

## Later prototype lessons

### Whip-as-normal-weapon approach
Useful references may exist, but direct use can conflict with BFCO/MVC and can collapse into ordinary melee/block behavior.

### Pull-base prototype
Mechanically important because ranged impact + pull worked.
Visual failure: presentation resembled a gun/artifact rather than a physical chain technique.

### Spell-left-hand prototype
Rejected:
- felt like a spell;
- chain appeared magically;
- no satisfying physical loop/windup.

## Rule

When a rejected version and a reference disagree, **the rejected version has zero positive visual authority**.
It may still contain a useful mechanic, path, config, or data point. Reuse only the proven useful subsystem, never the rejected presentation by inertia.

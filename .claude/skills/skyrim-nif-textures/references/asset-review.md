# Asset review checklist

## Geometry
- scale plausible relative to character
- no obvious self-intersection
- attachment point correct
- transforms applied/expected
- no proxy geometry left in final build

## Material
- all texture paths resolve
- no unintended missing/purple texture state
- material matches design identity
- normals read correctly
- alpha only where required

## In motion
- prop does not clip badly during its intended animation
- attachment does not drift from the intended forearm/hand
- chain silhouette remains legible
